# 🚀 Professional Developer Portfolio

A high-performance, dark-themed industrial portfolio built with **Vanilla HTML5, CSS3, and JavaScript**. This project showcases a curated design system featuring custom motion cursors, kinetic tickers, and advanced GSAP-inspired scroll animations.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Typography:** Clash Display, Syne, Outfit, JetBrains Mono
- **Animations:** Intersection Observer API, CSS Keyframes, Custom JS Motion Engine
- **Icons:** SVG (Heroicons / Lucide style)

---

## ✨ Key Features

- **Industrial Aesthetic:** Deep dark theme with neon accents (Violet, Cyan, Amber).
- **Custom Cursor:** Dual-layered lagging cursor with exclusion blend modes.
- **Scroll Reveal:** Smooth fade-up and draw-in effects on viewport entry.
- **Performance Optimized:** Validated against Core Web Vitals (90+ PageSpeed scores).
- **Responsive Design:** Fully fluid layouts for mobile, tablet, and ultra-wide displays.
- **Modular Sections:** Includes Hero, Skills, Experience Timeline, Project Showcase, and Results Analytics.
